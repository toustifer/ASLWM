Abstract

Building generalist agents that can autonomously perceive, reason, and act in open-world environments is a long-standing goal of AI research. While Vision-Language-Action (VLA) models have shown impressive results in game playing, they face three fundamental challenges: low sample efficiency (requiring hundreds of billions of pretraining tokens), prohibitive deployment cost (multi-billion parameter models with inference latency exceeding acceptable thresholds for real-time games), and weak long-horizon decision-making due to causal confusion and sparse rewards.

World Model-based Planning offers a principled alternative by learning environment dynamics and performing look-ahead search in latent space. However, all latent world models face a critical challenge: compounding error — small per-step prediction shifts accumulate over rollout length, causing imagined trajectories to diverge from reality. We identify a more insidious phenomenon we term Context Collapse: increasing the history context window to mitigate compounding error paradoxically causes the model to degenerate into a "video generation" mode where action signals are progressively ignored.

We propose the Action-Sensitive Latent World Model (ASLWM), a framework that ensures latent dynamics faithfully respond to action signals at arbitrary rollout depths. ASLWM combines three synergistic components: (1) a contrastive next-state prediction loss that directly supervises action sensitivity, (2) a Variational Inverse Dynamics Model (VIDM) that forces the encoder to encode action-relevant information via an information bottleneck, and (3) an action sensitivity metric based on a variational lower bound of mutual information. We additionally propose the Instruction-Grounded Latent Scorer (IGLS), a lightweight cross-modal alignment model (<100M params) that aligns language instructions with latent trajectories, enabling instruction-goal planning at millisecond-level latency on consumer GPUs.

Method

The Context Collapse Phenomenon

When the history context window is enlarged to anchor long-range predictions, the world model degenerates into a sequence-to-latent mode — it extrapolates future frames from historical patterns while increasingly ignoring injected action signals. This fundamentally undermines the model's utility as a planning tool, which critically depends on faithful action conditioning.

Three Synergistic Components
1. Contrastive Loss

Directly supervises action sensitivity by enforcing that predictions using the correct action are closer to the true next state than predictions using incorrect actions.

ℒcontrast = max(0, d(ztrue, žcorrect) − d(ztrue, žwrong) + m)

2. VIDM

Variational Inverse Dynamics Model constrains the encoder via an information bottleneck, ensuring action-relevant information is preserved in the latent representation.

ℒVIDM = −I(Z; A) + β · I(Z; X)

3. Action Sensitivity

Quantifies the world model's responsiveness to actions via the variational lower bound of mutual information I(at; zt+1 | zt).

I(at; zt+1|zt) ≥ H(at) + E[log qφ(at|zt,zt+1)]

Instruction-Grounded Latent Scorer (IGLS)

IGLS aligns language instructions (via MineCLIP text embeddings) with latent trajectories from ASLWM. By injecting action information through action-conditioned modulation, IGLS scores imagined trajectories against language goals, enabling instruction-following planning via CEM in the learned latent space.

Figure 2: Cumulative prediction error (MSE) over rollout horizon. ASLWM achieves 0.15 at 32 steps vs. 0.9 for the original LeWM — a 6× improvement. Models 1-4 (without action-sensitivity mechanisms) all exhibit rapid error accumulation, confirming that larger context and higher resolution alone do not solve the problem.

Key Finding: Simply increasing history context length or image resolution does not improve long-range prediction — it can even degrade it (Context Collapse). The combination of rollout-based joint training + structured VIDM + contrastive loss is necessary to achieve stable long-horizon rollouts (0.15 vs 0.90 cumulative error at 32 steps).

Contributions

1. ASLWM Framework

We systematically address the compounding error problem in latent world models. We identify the Context Collapse phenomenon and reduce 32-step cumulative error from 0.9 to 0.15 (6× improvement) through contrastive loss + VIDM co-design.

2. Lightweight Planning

ASLWM + IGLS (<100M params total, 20× smaller than mainstream VLAs) achieves competitive instruction-following performance with millisecond-level latency on consumer GPUs, meeting real-time game deployment requirements.

3. Built-in IDM

Action sensitivity ensures the world model is inherently an IDM, capable of generating high-quality pseudo action labels from unlabeled egocentric video — a path toward data self-expansion for embodied agent research.
